## Research question

How does generation speed degrade as the expert budget (hence the resident fraction) shrinks?

## Hypothesis

[HYPOTHESIS] (historical wording, narrowed 2026-10-11, see Interpretation and FH-017) With the store, model size has no memory ceiling; speed falls sub-linearly with residency (exponent d log speed / d log residency well below 1). [HYPOTHESIS] (the invariant) RAM peak minus expert budget stays constant at every budget.

## Setup

Qwen3-30B-A3B Q4_K_M + store, 4 threads, budgets 4 / 3 / 2 / 1.5 GiB (24.5% → 9.2% residency), 3 repetitions per point; six sweeps on five binaries over two days.

## Commands

```bat
argine benchmark Qwen_Qwen3-30B-A3B-Q4_K_M.gguf --expert-store --sweep-expert-budget 4G,3G,2G,1.5G
```

`raw/records.jsonl` — the exact records of Argine's `runs.jsonl` used here (sanitised: host and user name only). Full log: `data/raw/argine-v1/runs.jsonl`. `results.csv` is regenerated by `python tools/build_historical_data.py`.

## Result

[MEASURED] e.g. binary 3d91ef83 (2026-10-03 11:16): 6.52 / 5.18 / 4.35 / 3.70 tok/s. Exponent 0.58 +- 0.02 (Argine); 0.496 on the re-run inside EXP-004.

[MEASURED] RAM peak - budget = 1.520 GiB (+-0.001) in all 20 store runs of 2026-10-03 at every budget and read mode.

## Interpretation

[DERIVED] Sub-linear but not free: 2.67x less residency cost 1.63-1.76x speed. The hard memory invariant holds exactly (the constant is shared tensors + KV + runtime).

**Audit closure (2026-10-11).** Two separate conclusions:
- **A. Memory overhead / hard budget.** [SUPPORTED] On the tested 30B runtime, the non-expert memory overhead stayed approximately constant (RAM peak − budget = 1.520 GiB ± 0.001 in 20 store runs) while the expert-store budget changed. This supports the hard-budget interpretation. Strong result.
- **B. Speed vs residency.** [SUPPORTED] Throughput degradation over the measured range (4 → 1.5 GiB, 24.5% → 9.2% residency) was sub-linear. The exponents (0.58 ± 0.02, 0.496, 0.50–0.58 across sessions) are descriptive measurements of those sessions, not universal or high-precision constants.
- [SUPERSEDED] The broad "model size has no memory ceiling". Narrower reading: there may be no sharp capacity ceiling within the tested streaming regime, but there is a practical time/performance ceiling (FH-017).
- No rerun is required for closure ([historical audit](../../docs/research/HISTORICAL-AUDIT-EXP001-006.md)).

## Limitations

[LIMITATION] The exponent is a two-endpoint slope; between-session spread at the same point reaches 15% (EXP-018), larger than the reported +-0.02. Per-point hit rates were not logged in this period.
